# 폐 Planning 모델 제작 및 GGO 표현 가이드

대상: Blender 등에서 GLB/GLTF를 제작하는 3D 작업자. 이 문서는 Planning 목록 정렬과 GGO 셰이더가 적용되는 현재 뷰어 구현을 기준으로 합니다. 전체 규칙은 [MODEL_NAMING_CONVENTIONS.md](../MODEL_NAMING_CONVENTIONS.md)를 참고하세요.

## 1. 납품 전 확인할 사항

1. 폐 모델의 파일명 또는 뷰어 표시 모델명에 `LUNG`을 구분해 넣습니다. 예: `case_LUNG.glb`, `case_ROI_LUNG.glb`. `seg`나 `remnant`만 있는 모델은 그 이름만으로 폐 모델이라고 판정하지 않으므로 `LUNG` 모델명을 사용하세요.
2. 구조물별로 메쉬를 분리하고 **내보낸 GLB/GLTF의 메쉬 노드 이름**을 확인합니다. 재질 이름이나 Blender 컬렉션 이름만 바꾸면 개별 메쉬의 GGO 자동 적용을 보장하지 않습니다.
3. 한 모델 안에서는 메쉬 이름을 고유하게 지정합니다. 목록 제어는 이름을 키로 사용하므로 중복 이름을 피합니다.
4. 고형 병변과 GGO 영역은 `Cancer_1`, `GGO_1`처럼 별도 메쉬로 내보냅니다. 하나의 메쉬 안에서 재질 슬롯만 나누면 GGO 이름이 붙은 메쉬의 모든 재질 슬롯에 같은 GGO 스타일이 적용됩니다.
5. 뷰어에서 기본 목록 순서, Planning ON/OFF, 구조물별 숨김/복원, GGO 불투명도 변경을 확인합니다. 밝은 배경과 어두운 배경, 회전 시점에서 혈관·병변의 겹침도 확인합니다.

## 2. 구조물별 이름과 정렬

폐 목록은 **Lobes → Arteries → Veins → Bronchus → Cancer → Other → Volumes** 순으로 표시합니다. 같은 분류 안에서는 숫자를 인식해 `A2`가 `A10`보다 먼저 옵니다.

| 분류 | 권장 이름 예시 | 작업 시 주의점 |
| --- | --- | --- |
| Lobes | `RUL`, `LUL`, `Seg8`, `RULseg1`, `LUL_segment_3`, `Remnant`, `RULremnant` | `seg` 또는 `remnant`가 포함되면 대소문자·구분자 유무와 관계없이 Lobes입니다. |
| Arteries | `pulmonary_artery`, `S8_arteries`, `A2` | `Seg8_arteries`는 Lobes보다 Arteries 분류가 우선합니다. |
| Veins | `pulmonary_vein`, `Remnant_veins`, `V2` | `remnant`와 함께 있어도 Veins가 우선합니다. |
| Bronchus | `bronchus`, `airway`, `Seg8_bronchus`, `B2` | 기관지 이름이 있으면 Lobes보다 우선합니다. |
| Cancer | `Cancer_1`, `Tumor_1`, `Nodule_1`, `GGO_1`, `nodule_margin` | 병변·margin·주석 탐색용 분류입니다. GGO를 암으로 판정한다는 뜻이 아닙니다. |
| Other | 위 이름 규칙에 해당하지 않는 메쉬 | 알아보기 쉬운 실제 구조물 이름을 유지합니다. |
| Volumes | 기존 `vol` 포함 보조 메쉬 | `vol`은 예약된 목록 규칙입니다. 일반 폐엽·병변 이름에는 불필요하게 넣지 않습니다. |

병변/GGO 이름이 가장 먼저 분류되고, 그 다음 기관지·동맥·정맥, 마지막으로 폐엽 이름을 검사합니다. 예를 들어 `Seg8_GGO`는 Cancer 목록에 들어갑니다. 분류 단어를 여러 종류 섞어 넣지 않는 편이 좋습니다.

자체 이름으로 분류되지 않는 자식 메쉬는 가까운 부모 이름의 분류를 이어받습니다. 개별 메쉬에 구조물 이름을 직접 지정하면 더 명확합니다. 이 상속 규칙은 **목록 분류**에 적용되며, 부모 이름이 `GGO`라고 자식 메쉬에 GGO 셰이더가 자동으로 적용되는 것은 아닙니다.

목록 분류와 불투명도 조절 가능 여부는 별개입니다. 임의 이름의 구역 메쉬에도 불투명도 컨트롤이 필요하면 대문자 `T_` 접두사를 붙입니다. 예: `T_Seg10`, `T_custom_region`. GGO 이름은 별도의 `T_` 없이도 불투명도 조절 대상입니다.

## 3. Planning / ROI vessel 사용 규칙

기존 ROI vessel 버튼으로 Planning을 켭니다. ON 상태에서는 기존 ROI 강조와 함께 목록에 분류별 제목·개수·일괄 숨김/표시가 나타납니다. OFF 상태에서도 구조물별 기본 정렬은 유지됩니다. 다른 모델을 로드하거나 측정 모드로 전환하면 Planning은 해제됩니다.

폐 모델로 인식되고 모델명에 `ROI`가 포함되면 로드 완료 후 자동으로 활성화됩니다. 수동으로 켜는 용도라면 모델명에 `ROI`를 넣을 필요가 없습니다.

- ROI 기준 영역은 `Target_A`, `target a`, `target-a` 이름의 메쉬로 지정합니다. 단순히 `Target`이라고만 쓰면 ROI 기준 영역으로 인식되지 않습니다.
- ROI는 기준 영역과 혈관의 **바운딩박스 교차**로 메쉬 전체의 강조 여부를 정합니다. 여러 Target A가 있으면 합친 바운딩박스를 사용합니다. 표면 사이의 정밀한 교차 판정이나 절제 범위 계산이 아닙니다.
- 기준 영역이 없으면 인식된 전체 폐혈관·기관지를 컬러 대상으로 사용합니다.
- `arteries`가 포함된 이름은 기존 예외 규칙으로 Target A와의 교차 여부에 관계없이 컬러를 유지합니다. 따라서 `A2`와 `S8_arteries`는 목록에서는 같은 Arteries지만, Target A가 있는 ROI 강조에서는 동작이 다를 수 있습니다.
- GGO는 ROI ON/OFF 모두 전용 질감을 유지합니다. 일반 Cancer/Tumor/Nodule은 고형 병변 재질과 구분해 제작합니다.

## 4. GGO 메쉬 제작

| 이름 | 자동 GGO 적용 | 이유 |
| --- | --- | --- |
| `GGO`, `GGO1`, `GGO_1`, `GGO.001` | 예 | 독립된 GGO 토큰, 뒤 숫자 및 구분자를 허용합니다. |
| `T_GGO_2`, `RUL_GGO_1` | 예 | 앞뒤 단어가 구분되어 있습니다. |
| `ground glass`, `ground-glass opacity` | 예 | ground glass 표기를 인식합니다. |
| `RULGGO`, `GGOregion` | 아니요 | GGO가 다른 영문 단어에 붙어 있어 토큰으로 인식되지 않습니다. `RUL_GGO`, `GGO_region`으로 지정합니다. |
| `Cancer`, `Nodule`, `infiltration` | 아니요 | 해당 이름만으로 GGO 영역을 추정하지 않습니다. |

GGO로 표시할 분할 영역을 별도 메쉬로 내보내세요. 뷰어는 해당 영역을 생성하거나 범위를 수정하지 않습니다. 고형 병변도 보여야 한다면 Cancer/Nodule 메쉬를 따로 유지합니다. 같은 위치의 동일한 GGO 메쉬를 중복해서 내보내면 반투명 레이어가 겹쳐 더 진하거나 불안정하게 보일 수 있으므로 피합니다.

질감용 UV와 노이즈 이미지 텍스처는 필요하지 않습니다. 뷰어가 GGO 메쉬의 기본색·거칠기·금속성·기본 불투명도를 설정하고, base-color/alpha/normal/bump/displacement 맵을 제거합니다. Blender에서 구름 무늬를 베이크하거나 원본 재질의 투명도만으로 최종 외관을 맞출 필요가 없습니다. 최종 결과는 뷰어에서 확인하세요.

## 5. GGO 셰이더 처리 방식

구현: [GgoMaterial.js](../src/materials/GgoMaterial.js), 이름 판정: [lungStructures.js](../src/utils/lungStructures.js).

### 희끗한 질감

Three.js `MeshStandardMaterial`의 조명 계산을 유지하면서 `onBeforeCompile`로 밝기와 알파 계산을 추가합니다. 메쉬의 로컬 좌표를 바운딩박스 중심과 가장 긴 축 길이로 정규화하고, 굵은 3D 노이즈와 가는 노이즈를 섞습니다. 여기에 가느다란 밝은 무늬를 조금 더해 균일한 반투명 플라스틱보다 얼룩진 구름처럼 보이게 합니다.

노이즈에는 시간값을 사용하지 않습니다. 모델을 회전해도 무늬는 메쉬에 붙어 있고, 움직이는 안개처럼 흐르지 않습니다. 정규화는 각 메쉬의 로컬 크기를 기준으로 하므로 GGO를 여러 조각으로 분리하거나 스케일을 지오메트리에 적용해 다시 내보내면 무늬 크기가 달라질 수 있습니다.

### 부드러운 경계와 투명도

표면 법선과 카메라 방향이 비스듬해지는 실루엣 부근에서는 알파를 낮춥니다. 형상을 깎거나 경계를 이동하는 것이 아니라 표면의 보이는 강도를 낮추는 처리입니다. 기본 opacity는 `0.68`이고 여기에 위치별 노이즈와 경계 계수가 곱해지므로 **모든 픽셀이 68% 불투명한 것은 아닙니다.** 목록에서 opacity를 최대로 바꿔도 GGO의 위치별 반투명 표현은 유지됩니다.

`depthWrite=false`로 GGO 자체가 깊이 버퍼를 막지 않게 하고, `depthTest=true`로 이미 기록된 앞쪽 구조물의 깊이를 확인합니다. 따라서 항상 모든 구조물 위에 표시되는 효과가 아닙니다. 여러 반투명 폐엽·혈관과의 최종 겹침은 각 메쉬의 깊이 설정과 렌더링 순서에도 영향을 받습니다.

### 현재 기본값과 개발자 조절 지점

아래 값은 파일 내부 설정이며 별도 UI 슬라이더가 아닙니다. 3D 작업자는 메쉬와 이름을 준비하고, 질감 변경이 필요하면 해당 항목을 개발자에게 전달하면 됩니다.

| 항목 | 현재 값 | 바꾸면 달라지는 점 |
| --- | --- | --- |
| 기본색 | `#e1ebed` | 밝은 회백색의 색조 |
| Emissive 색 / 강도 | `#c0d4db` / `0.12` | 조명이 약한 부위의 밝기 보조 |
| Roughness / Metalness | `0.95` / `0` | 무광에 가까운 표면 반사 |
| 기본 opacity | `0.68` | 전체 표시 강도. 뷰어 불투명도 컨트롤로도 변경 가능 |
| Cloud 노이즈 | 주파수 `4`, `11`; 가중치 `0.65`, `0.35` | 주파수를 높이면 더 작은 얼룩, 가중치를 바꾸면 굵은/가는 무늬 비중 변화 |
| Wisps 노이즈 | 주파수 `17`; 밝기 기여 `0.08`, 알파 기여 `0.1` | 가느다란 흰 무늬의 크기와 강조 정도 |
| 실루엣 계수 | `0.28`~`1.0` | 가장자리의 옅어지는 정도 |
| Alpha test | `0` | 낮은 알파를 임계값으로 잘라내지 않음 |

이 효과는 **분할된 메쉬 표면의 시각화**입니다. CT voxel/HU를 읽는 볼륨 렌더링, 실제 밀도 측정, 체적 내부의 광산란 표현은 포함하지 않습니다. 현재 자동 검증은 테스트 메쉬의 셰이더 컴파일과 상태 전환을 확인했으며, 납품용 실제 폐 모델의 표현 강도는 별도로 확인해야 합니다.

## 6. 문제가 있을 때

| 증상 | 먼저 확인할 것 |
| --- | --- |
| Planning 버튼이 보이지 않음 | 파일명/표시 모델명의 `LUNG` 구분 표기. `Seg8`, `Remnant`만으로는 폐 모델 판정이 안 됩니다. |
| 구역이 Other로 분류됨 | 실제 내보낸 메쉬 이름에 `seg`, `remnant` 또는 폐엽 이름이 있는지 확인합니다. |
| GGO가 일반 색상으로 보임 | 메쉬 이름의 GGO 토큰과 구분자를 확인합니다. 재질/부모 그룹 이름만 GGO인지 확인합니다. |
| 고형 병변까지 뿌옇게 변함 | 고형 병변이 GGO 메쉬에 합쳐졌는지 확인하고 별도 메쉬로 분리합니다. |
| GGO가 가려지거나 너무 진함 | 폐엽의 표시/불투명도, 중복 GGO 메쉬, 모델의 앞뒤 관계를 확인합니다. |
| ROI에서 예상보다 많은 혈관이 컬러로 보임 | Target A의 바운딩박스, 여러 Target A의 합집합 범위, `arteries` 이름 예외를 확인합니다. |
